Bazel Practicum

Learn Bazel the way a Python developer actually meets it: start with a single py_binary, then grow it into a monorepo with tests, PyPI dependencies, configurations, generated files, and a second language (Go). Every lesson has a Bazel simulator right in the page, so you can edit BUILD files and run bazel query or bazel build as you read. Every module also has labs that run real Bazel 9 on your machine, installed by Pixi and graded by real builds and tests.

How this course works

1 · Read and try

Lessons mix explanation with sandboxes: small workspaces you can edit, with a command line for bazel query, build, and test.

2 · Meet the errors

Bazel's error messages are precise once you can read them. Sandboxes break on purpose so you see each one before it surprises you at work.

3 · See the graph

Visualizers show the three phases of a build and exactly what re-runs when you change one file.

4 · Practice

Graded exercises check your BUILD files in the simulator. Hints and solutions are there when you need them.

5 · Lab it for real

Labs run real Bazel: pixi run start m01-lab1, edit, then pixi run grade m01-lab1.

6 · Build a monorepo

Level 1 ends with a capstone: a Python service and a Go CLI in one repository, graded by real bazel test and bazel query.

Level 1 (Building with Bazel) is available now. Level 2 (toolchains, hermeticity, remote caching and execution, CI) and Level 3 (custom rules, providers, aspects) are on the roadmap.

All local work uses Pixi, which installs Bazelisk; Bazelisk then runs the Bazel version each workspace pins. From a clone of bazel-practicum: pixi install once, pixi run serve to open this site, pixi run labs to list labs, pixi run start m01-lab1 to copy a starter workspace into work/, and pixi run grade m01-lab1 to check it with real Bazel.

Level 1 takes about 25–30 hours including labs and the capstone. You should be comfortable with Python packages, imports, and pytest. No Go experience is needed: Module 07 teaches the little Go it uses.
